Checklisten

Checklisten sind Listen mit Checkboxen. Verwende - [ ] für offene und - [x] für erledigte Aufgaben.

In Tools wie GitHub, Notion oder Obsidian werden daraus klickbare Checkboxen.

- [ ] Offen
- [x] Erledigt
- [ ] Noch offen
  • More

    - [ ] erstellt eine offene Checkbox. Das Leerzeichen zwischen den Klammern ist wichtig.

    Close
  • More

    - [x] erstellt eine abgehakte Checkbox. Das x steht für erledigt.

    Close
  • More

    Checklisten sind normale Listen, du kannst sie mit anderen Markdown-Elementen wie **fett** kombinieren.
