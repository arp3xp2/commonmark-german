Listen

Ungeordnete Listen können Sternchen *, Plus + oder Bindestriche - als Aufzählungszeichen verwenden.

Geordnete Listen verwenden Zahlen gefolgt von einem Punkt . oder einer Klammer ).

* Äpfel
* Orangen
* Birnen

1. Erstens
2. Zweitens
3. Drittens
  • More

    Verwende *, + oder - um eine Liste zu erstellen. Jede Liste muss durchgehend das gleiche Zeichen verwenden.

    Nach jedem Aufzählungszeichen ist ein Leerzeichen erforderlich.

    Geordnete Listen beginnen mit einer Zahl gefolgt von einem . oder ) und einem Leerzeichen.

    Keine Liste gewünscht? Verwende einen Backslash zum Escapen:

    12\. Eine gerade Zahl.
